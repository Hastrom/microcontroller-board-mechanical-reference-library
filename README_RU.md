# Механическая STL/STEP-библиотека плат — публичная кандидатная версия v1.3-rc1

**17 типов плат. Создано ChatGPT (OpenAI) по запросу владельца проекта Hastrom.** Это независимая библиотека для предварительного проектирования корпусов и креплений, а не официальный продукт Arduino или OpenAI.

В архиве находятся **STL**, отдельные **STEP**, каталог `CATALOG.csv`, отчёт `QA_REPORT.json`, документы о происхождении и лицензии. Исходные `.brd`, `.sch`, `.kicad_mod`, чужие STEP, фотографии и логотипы сюда **не включены**.

**Главное ограничение:** геометрическая замкнутость STL не означает заводскую точность. Большинство сборок и высот компонентов реконструированы. Отверстия из KiCad источников относятся к сопрягаемым шилдам/сокетам, **не к гарантированной сверловке настоящих плат Arduino**. Для Arduino Micro особенно важно: справочные отверстия под сокет нельзя считать заводскими крепёжными отверстиями Micro. Перед изготовлением корпуса всегда сверяйте конкретную физическую плату.

- `models/` — приближённые полные сборки, отверстия, компоновка.
- `precision/UNO_R3_DIP/` — механические PCB-модели из числовых координат официального EAGLE UNO R3 Rev3e (под CC BY-SA 4.0).
- `precision/{ARDUINO_MICRO,DUE,GIGA_R1_WIFI,LEONARDO,UNO_R4_WIFI}/` — модели по справочным KiCad footprint для сопрягаемых плат.
- `THIRD_PARTY_SOURCES.md` — указаны авторы, лицензии, ссылки и изменения.
- `EXCLUDED_PRIVATE.md` — перечень моделей, не включённых в публичный выпуск.

Лицензия **CC BY-SA 4.0** применяется к соответствующим материалам в пределах передаваемых прав; авторство источников сохраняется, изменения указаны. Не распространяется на товарные знаки и патенты. В частности, **Arduino® — торговая марка Arduino S.r.l.**, использована лишь для описания изделий. Никакой поддержки, лицензирования бренда или заводской сертификации не заявлено.

**Создано ChatGPT (OpenAI)** — описание инструмента генерации, а не участие или одобрение OpenAI.

Модели не пригодны в качестве единственного основания для точного сверления, проверки изоляции, высоковольтных или тепловых расчётов. **Оригинальная личная библиотека v1.3 сохранена без изменений.**
