# Excluded from this public candidate

These are **not** deleted from the user's original private v1.3 archive.

- **Mega 2560 R3 CAD-derived models and STEP/STL**: official EAGLE reference archive supplied to the user did not contain a dedicated license notice; publication should wait for exact-source distribution terms to be confirmed. Model may be open hardware, but no claim of rights clearance is made here.
- **Nano V3.3 Reference CAD-derived models and STEP/STL**: derived from a third-party modified EAGLE project with no sufficiently explicit grant from the modifier found at review.
- **SparkFun Pro Mini 328 CAD-derived models and STEP/STL**: the source README points to CC ShareAlike 3.0, but this conservative single-license candidate excludes it until separate CC BY-SA 3.0 licensing and attribution can be packaged and reviewed.
- **Prior UNO R3 full assembly STL**: older multi-shell item was reported non-watertight; the mechanical EAGLE-derived board geometry remains included.
- Original `.brd`, `.sch`, `.kicad_mod`, downloaded CAD/STEP, source archives, screenshots, logos, private previews, unreviewed source generators and private file inventories.

As a result, **17 of the 20 private configurations** are represented in this release. Models may be added later only after explicit source/license review and dimension validation.
